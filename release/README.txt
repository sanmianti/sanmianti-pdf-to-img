PDF 转图片 1.0.0

最低系统：Windows 7 SP1
支持架构：x86 与 x64 Windows（安装包内程序为 Win32 x86）
输出格式：144 DPI、白色背景、24 位 BGR PNG

安装：运行 PdfToImage-Setup-1.0.0.exe。
使用：拖入一个 PDF，或单击拖拽区域选择 PDF。
说明：软件完全离线，不依赖 Java、.NET 4.x 或 VC++ Redistributable。

PDFium：109.0.5406.0，Win32 x86，非 V8、非 XFA。
构建机自测：Windows 10 22H2 x64；详见仓库 README.md。
